# soma_pares_vetor_funcao.c
Projeto de funções e vetores na linguagem C

Este programa em C solicita 5 números inteiros ao usuário, armazena em um vetor e calcula a soma apenas dos números pares, utilizando uma função separada.

## Lógica usada:
- Vetor
- Função com passagem de vetor por parâmetro
- Estrutura de repetição e condicional

## Exemplo de execução:

Digite 5 números inteiros:  
10  
3  
8  
5  
2  

A soma dos números digitados que são pares é: 20
